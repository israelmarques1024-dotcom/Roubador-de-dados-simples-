# Roubador de Dados Simples

Uma tela de login feita em JavaScript e HTML. **Não tem banco de dados** — realmente não consegue roubar seus dados, relaxa! É só um projeto simples para testar habilidades.

Criado por **Israel Marques** (12 anos).

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Sobre

Esse projeto simples é uma coisa que eu fiz para testar minhas habilidades criando uma tela de login. Queria muito ver como funcionava a parte visual e a validação no front-end.
