## ✨ Funcionalidades

- 🖥️ Tela de login estilizada
- ✅ Validação de campos vazios
- 🔔 Feedback visual para o usuário
- 🎨 Design responsivo
- ⚡ JavaScript puro, sem dependências

---

## 🚀 Como rodar

```bash
# Clone o repositório
git clone https://github.com/israelmarques1024-dotcom/Roubador-de-dados-simples-.git

# Entre na pasta
cd Roubador-de-dados-simples-

# Abra o index.html no navegador
```

Ou simplesmente abra o arquivo `index.html` no seu navegador favorito. Não precisa instalar nada!

Roubador-de-dados-simples-/

## 🎯 Sobre o projeto

Esse projeto simples foi feito para testar minhas habilidades criando uma tela de login completa no front-end. Queria ver como funcionava a validação de formulários, feedback visual e design responsivo sem usar frameworks — tudo na mão com HTML, CSS e JavaScript puro.
